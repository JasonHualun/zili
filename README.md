# 字里

一个 Chrome 浏览器插件，在你上网的地方帮你写、帮你读：

- **写**：输入框里润色、扩写、帮你写回复，去掉 AI 味。
- **读**：划词或截图，就能翻译、讲解、解题、核验真假。
- **看**：YouTube 英文字幕实时翻成中文；把信息流里不想看的内容一键藏掉；解除网页的禁止复制。
- **练**：收藏英文生词并朗读，和“英语老师小猫”语音对话练口语。
- **收**（进阶）：一键把网页交给你电脑上的 AI 助手，整理进你自己的文件夹。

所有内容写进输入框之前都要你点确认，**字里不会替你点发送或发布**。

## 安装（3 分钟）

不用上架商店，下载后直接加载：

1. **下载**：点本页右上角绿色的 `Code` → `Download ZIP`，解压到一个以后不会删的地方（比如“文稿”）。
   会用 git 的话也可以：`git clone https://github.com/JasonHualun/zili.git`
2. **加载插件**：在 Chrome 地址栏打开 `chrome://extensions`，打开右上角的“开发者模式”，点“加载已解压的扩展程序”，选择解压出来的 **`huashao-tone`** 文件夹（选里面这一层，不是外面那层）。
3. **填 API Key**：点浏览器右上角的拼图图标，把“字里”固定到工具栏。点开字里 → 右上角齿轮 → 模型，选一家服务商，填你自己的 API Key，再点“检查 API”确认能连上。

**支持的模型服务商**：DeepSeek（默认）、小米 MiMo、MiniMax、智谱 GLM、豆包（火山方舟）、通义千问（阿里云百炼），以及兼容 OpenAI 格式的自定义中转站。

- 截图类功能（框选识别、⌘V 粘贴截图、聊天发图）要选标着“可识图”的模型。
- 核验真假和问“今天、最新、价格”这类时效问题，要选标着“可联网”的模型。

### 用通义千问或英语陪练？再多填一个“业务空间 ID”

用 DeepSeek、智谱等其他服务商的可以跳过这一节。用通义千问（阿里云百炼）的，只有下面两种情况要多填一项：

- 要用**英语陪练**（语音对话只能走通义千问）；
- 你的通义千问 API Key 是 **`sk-ws-` 开头**的新版 Key（老版 `sk-` 开头的不用填）。

怎么填：

1. 打开阿里云百炼控制台（bailian.console.aliyun.com），登录你自己的账号。
2. 在控制台右上角找到“业务空间”，复制它的 ID（形如 `ws-xxxxxxxxxxxx`）。注意要选**北京**地域。
3. 在百炼控制台的“API Key”页面创建或复制一个 API Key。
4. 先在字里的设置 → 模型里选“通义千问”，填上这个 API Key。
5. 点开字里弹窗首页的“英语陪练”，打开陪练小窗，点开始。第一次会弹出“语音陪练设置”，把**业务空间 ID** 粘贴进去，确认。下面的“语音专用 API Key”可以不填，不填就沿用第 4 步的 Key。

只需要填一次，就算你只用文字功能、不练口语，也要在这里填：填好以后，英语陪练和文字类功能（润色、回复等）都会自动走你的业务空间。这个 ID 不是密钥，只保存在你自己的浏览器里。

> 装好后不要移动或删除这个文件夹，Chrome 每次都从这里读插件。以后更新就用新版文件覆盖，然后在 `chrome://extensions` 里点字里的刷新按钮，再刷新网页。

## 功能一览

### 一、在输入框里写

| 功能 | 怎么用 | 做什么 |
|---|---|---|
| 润色 | 在任何输入框打字，旁边会出现“润色” | 意思和长度不变，只把话改顺、改自然 |
| 补充润色 | 同上，点“补充润色” | 按你写的主题续写、扩写，可选短、中、长，不编造事实 |
| 帮你写回复 | 在 X、小红书、抖音、YouTube 等页面的回复框里打两个字，或者写“帮我写条回复” | 自动读原帖，按你的口吻写一条回复 |
| 自动润色 | 设置 → 写作助手里打开（默认关） | 打字停顿约 1 秒就自动润色。可以选“直接写入”，或者先出候选再确认 |
| 结果卡 | 每次生成后出现 | 可以写入、复制、恢复原文、重写一版、临时调口吻、继续追问 |

### 二、在网页上读

| 功能 | 怎么用 | 做什么 |
|---|---|---|
| 划词助手 | 用鼠标选中网页上的一段文字 | 弹出小工具条：**回复 / 翻译·学英语 / 讲解 / 核验**，会自动判断你想干嘛 |
| 翻译·学英语 | 选中英文 | 给出译文，展开“学一点”能看到构词、重点表达、句子拆解、例句，可朗读、可收藏 |
| 核验 | 工具条里点“核验” | 分开判断“消息真不真”和“像不像 AI 写的”，附来源（需要可联网模型） |
| 框选识别 | 弹窗或小猫里点“框选识别”，在网页上拖一个框 | 识别框里的内容，可切换成回复、解释、翻译、解题、提取文字、核验（需要可识图模型） |
| 粘贴截图 | 在网页上（没点进输入框时）按 ⌘V | 剪贴板里的截图直接识别 |
| 继续问 | 任何结果卡下方 | 围绕这张卡连续追问，还能附图 |
| 关键词回复 | 设置 → 写作助手 → 关键词回复（默认关） | 自己设“关键词 → 固定回复”，最多 50 条。选中的文字命中关键词就直接给回复，不调用模型、不花钱 |

### 三、网页小工具（弹窗首页）

| 功能 | 做什么 |
|---|---|
| 一键脱水 | 按你的“脱水要求”（比如“只留 AI 相关”“去掉八卦”）把当前页信息流过一遍，不相关的卡片藏起来；再点一次恢复。YouTube、小红书、B 站做过适配 |
| 本页复制 | 让禁止复制的网页恢复划选和右键菜单；图片右上角出现“复制图片 / 保存”。不调用模型，刷新后失效 |
| 字幕翻译 | 翻译当前视频的字幕，提前预译约 45 秒，跟着进度显示中文。YouTube 要先在播放器里打开英文字幕。不录音，也不下载视频 |
| 框选识别 | 同上文 |
| 英语陪练 | 打开一个小窗，和“英语老师小猫”语音对话练口语，说“收藏一下”就能把词句存进英语收藏。需要通义千问（阿里云百炼）的 API Key 和业务空间 ID，在小窗里填 |

### 四、漂浮小猫“卡路里”

网页右下角有一只暹罗猫，可以拖动，双击回到右下角。点它会依次切换三个面板：

- **对话**：直接跟它说话。每次发送都会附上当前网页的标题、作者、正文开头、选中的文字等，所以说“帮我回复这个视频”不用自己贴内容。它写出来的回复、评论、帖子会单独显示成一张卡片，可以“写进输入框”（只填入，不发送）或复制。还能在对话里直接让它：
  - 一键脱水、清掉广告；
  - 开关本页复制、字幕翻译，启动框选识别；
  - 换皮肤，改口吻、标点、表情；
  - 开关自动润色、划词助手、架构师模式、关键词回复。
  改动立即生效，下面有“撤销”。API Key、模型和总开关不能用对话改。
- **功能**：一键脱水、本页复制、字幕翻译、框选识别。
- **收纳**：见下面的“本地收纳”。

### 五、在 AI 聊天页（架构师模式）

在 ChatGPT、Claude、Gemini、DeepSeek、通义千问、Poe 等 AI 聊天页面打字时，字里会推荐一张合适的“方法卡”，比如第一性原理、奥卡姆剃刀、五个为什么、失败预演，也可能问你一个澄清问题。点“写进聊天框”就能用上。

- 内置 18 张方法卡，可以自己“录入方法”：粘贴一段 Prompt，AI 帮你整理成卡。
- 设置 → 写作助手 → 架构师模式打开后（默认关），由模型来判断推荐什么；关着时只用本地关键词匹配，不花钱。

### 六、口吻和外观

- **口吻底座**：所有写作默认带作者花伦的口吻（像一个有见识的普通人在聊天），并自带“去 AI 味”红线：“值得注意的是”“归根结底”这类词和套路句式会被拦下，自动重写一次。
- **四个预设**：平常说 / 直接说想法 / 稳一点说 / 轻松一点。
- **四个滑块**：聊天感、观点强度（低于 60 时顺着对方接话，80 以上才直接表达不同意见）、句式（肯定还是疑问）、长度。
- **建立我的表达**：6 个场景逐题写你平时真实会说的话，也可以直接粘贴你以前写过的内容，再选标点和表情习惯。之后字里写出来的东西会更像你。
- **外观**：四款皮肤（雾蓝、松墨、暖砂、夜墨），猫的衬衫颜色会跟着换；可以关掉漂浮猫。

## 隐私

- API Key、口吻档案、英语收藏、聊天记录都只存在你自己的浏览器里。字里没有服务器，不收集任何数据。
- 只有你主动使用某个功能时，相关文字或截图才会直接发给你选的那家模型服务商。

## 进阶：本地收纳（仅 macOS）

在网页上点小猫 → 收纳，可以把当前网页（或选中的文字、一条帖子，可以附截图和备注）交给你电脑上的 AI 助手，让它整理成 Markdown 笔记，存进你自己选的文件夹。可以选“保存”或“做选题”；也可以先“加入待收纳”攒一批（最多 30 条），再一次发出。

**支持的 AI 助手**（装了哪个都行）：Claude Code、Codex、Gemini CLI、Qwen Code、OpenCode、Hermes。

**安装**：在终端运行下面两行。第一行把 `cd ` 后面换成你的字里文件夹，也可以输入 `cd ` 后直接把文件夹拖进终端窗口：

```bash
cd ~/Documents/zili
python3 zili-bridge/install.py
```

安装程序会：

1. **扫描**：找出你电脑上装了哪些 AI 助手；
2. **逐个问你**：允许字里调用哪一个，没允许的永远不会被调用；
3. **问收纳文件夹**：东西存到哪里，回车就用默认的 `文稿/字里收纳`；
4. **问收纳 Skill**：有自己的 Skill 就填上名字，没有就用字里自带的整理规则：按主题分文件夹，每条写标题、原链接、要点摘要和正文。

装好后，在 `chrome://extensions` 里刷新字里，再到字里的设置 → 本地收纳里选用哪个助手。

- **安全**：AI 助手只能在收纳文件夹里读写文件，不会全自动执行其他命令。网页内容只被当作资料，里面要求做的事一律不执行。
- **以后要换助手或换文件夹**：重新运行一次安装命令就行。
- **卸载**：运行 `python3 zili-bridge/install.py --uninstall`，收纳文件夹里的内容不会动。
- **说明**：目前作者只完整实测过 Hermes，其他助手的调用方式已经写好，但还没逐个实测。遇到问题欢迎提 Issue。
